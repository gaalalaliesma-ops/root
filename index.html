Los estilos de natación

Cada estilo combina una posición, una coordinación y una técnica de respiración propias.

01

Crol

Alterna los brazos y mantiene una patada continua. Es el estilo más rápido en competición.

02

Espalda

Se nada boca arriba, con brazadas alternas y una patada constante desde la cadera.

03

Braza

Brazos y piernas se mueven de forma simétrica, con una pausa de deslizamiento.

04

Mariposa

Ambos brazos recuperan juntos y la ondulación del cuerpo acompaña la patada de delfín.

La web también se entrena

Esta revista de natación está construida con HTML y CSS. Así se aplican los lenguajes de marcas al crear una página real.

01 / MARCADO

HTML y sus versiones

HTML estructura las noticias, la agenda y las secciones. Ha evolucionado desde HTML 4.01 y XHTML 1.0 hasta HTML5, hoy mantenido como estándar vivo.

<article> noticia de natación </article>
02 / DOCUMENTO

Secciones y atributos

<header>, <nav>, <main>, <article> y <footer> describen la página. Atributos como href, src y alt enlazan contenidos y describen imágenes.

<img src="piscina.jpg" alt="Nadador en la piscina">
03 / HTML Y XHTML

Dos sintaxis relacionadas

Ambos usan elementos y atributos para marcar contenido. XHTML aplica reglas XML estrictas: etiquetas en minúscula, atributos entre comillas y elementos cerrados. Es útil cuando un sistema de gestión necesita procesar contenido como XML.

HTML: <br> · XHTML: <br />
04 / HERRAMIENTAS

Del editor al navegador

Un editor como Visual Studio Code facilita escribir y organizar los archivos. El navegador permite previsualizar la página y sus herramientas de desarrollo ayudan a revisar el resultado.

index.html + styles.css → navegador

05 / HOJAS DE ESTILO

CSS: el diseño fuera del contenido

Una hoja externa, styles.css, reúne los colores, la tipografía y la distribución de Carril. Separar estilo y contenido facilita actualizar todas las páginas a la vez; las media queries adaptan la revista a móvil y escritorio.

@media (max-width: 600px) {
  .news-grid { grid-template-columns: 1fr; }
}
